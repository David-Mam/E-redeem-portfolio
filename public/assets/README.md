# Public Assets Directory

Place your static images and videos here to serve them directly via absolute URL paths in your website.

### Subdirectories:
- `public/assets/images/` - Place image files (PNG, JPG, SVG, WebP, GIF, etc.)
- `public/assets/videos/` - Place video files (MP4, WebM, etc.)

### Usage Examples:
- **Image**: `<img src="/assets/images/example.png" alt="Example" />`
- **Video**: `<video src="/assets/videos/example.mp4" controls />`
- **CSS background**: `background-image: url('/assets/images/example.png');`
